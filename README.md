# Инструмент для автоматической синхронизации и отправки локальных изменений в несколько Git-репозиториев одновременно

## 1. Основные возможности 

Этот скрипт создан для автоматизации рутинных операций при работе с мульти-репозиториями и решает сразу несколько классических проблем Git:
 * Мультихостинг одной командой
   * Позволяет отправлять актуальные изменения (коммиты) одновременно на любое количество удаленных платформ (GitHub, GitLab, Gitea, Bitbucket и др.) без необходимости вручную прописывать git push для каждого адреса.
 * Гибкое сопоставление веток
   * Поддерживает отправку текущей локальной ветки на разные целевые ветки в удаленных репозиториях (например, синхронизация локальной ветки разработки с main на одном хостинге и с master на другом). Если ветка назначения в файле конфигурации не указана явно, скрипт автоматически подставит текущую ветку.
 * Безопасный Force Push с защитой от ошибок
   * Если история на удаленном сервере отличается и стандартный push отклонен, скрипт собирает проблемные адреса в отдельный список.
   * Перед применением принудительной отправки (--force) система выводит предупреждение и требует ввести полное слово подтверждения (yes), исключая случайное затирание чужих коммитов или истории на сервере.
 * Интерактивная цветовая индикация
   * Все этапы работы скрипта (проверки, процесс отправки, успешные операции и ошибки) подсвечиваются разными цветами (зеленый, красный, синий, желтый), для наглядности и читаемости с первого взгляда.
 * Кроссплатформенность
   * Корректно работает в различных окружениях: Git Bash (Windows), Linux и macOS. Если возникают проблемы, обязательно напишите о них.

## 2. Структура проекта

Для корректной работы скрипта, положите его и список ссылок в корень проекта.

your-project/
├── autopush.sh      # Основной скрипт синхронизации
├── git-links.txt    # Файл с адресами удаленных репозиториев
└── README.md

***

## 3. Настройка файла конфигурации (git-links.txt)
Каждая строка содержит 

* URL удаленного репозитория и (опционально) целевую ветку через пробел.

* Если ветка не указана, берется текущая локальная ветка.

Пример:

https://github.com/user/repo.git main
https://gitlab.com/user/repo.git master
git@gitea.com:user/repo.git

ПОЖАЛУЙСТА, не забывайте добавлять файл git-links.txt в .gitignore в целях безопасности.
